# Outfit Bone Sync（衣装のボーン合わせ）

アバターのボーン（Armature）の Position・Rotation・Scale を改変しているときに、そのアバター用の衣装を着せると、衣装が改変前の体に合わせた形のままでずれます。このツールは、アバターのボーンを改変前から変えた分だけ、衣装のボーンも同じように変えて、改変後の体に合わせます。

MIT ライセンスで公開しています（同じフォルダの `LICENSE.md`）。

## 導入

1. VCC（VRChat Creator Companion）か ALCOM に、リポジトリ `https://vpm.mosin.jp/index.json` を追加します。
2. プロジェクトの管理画面で **Outfit Bone Sync（衣装のボーン合わせ）** を追加します。`Packages/jp.mosin.outfit-bone-sync` に入ります。

VPM を使わない場合は、[Releases](https://github.com/ryoctrl/OutfitBoneSync/releases) の `.unitypackage` をインポートしても入れられます（入る場所は同じです）。

## 使い方

1. 衣装をアバターの子に置く（Modular Avatar の Setup Outfit 済みでも、まだでもよい）。
2. メニュー `Tools/Outfit Bone Sync`（または Hierarchy の右クリック `Outfit Bone Sync`）でウィンドウを開く。ボタンを押すまで、シーンは変更されない。
3. **アバター**: 「アバター」欄にドラッグ（アバターの中のオブジェクトでも可）、または「シーンから選択」で選択。開いた時点で Hierarchy の選択がアバター・衣装であれば自動で設定。「シーン」の表示で選択を確認。「変更済みボーン」に、アバターで基準値から変更されたボーンの一覧。
4. **対象衣装**: アバター直下の衣装の一覧。適用する衣装にチェック（衣装を選択して開いた場合は、その衣装のみチェック）。一覧に無い衣装は「衣装を追加」で指定。衣装・ボーン（Armature を含む）は GameObject の欄で表示し、クリックで Hierarchy 上でハイライト（「変更内容」の表・「変更済みボーン」も同じ）。Hierarchy で選択中の衣装は行に背景色。
5. **変更内容**: 衣装ごとに、変更されるボーンと Position・Rotation・Scale の「現在」「適用後」の値。適用済みの衣装は「適用前」（記録された元の値）も表示。
6. **適用** を押す。衣装にコンポーネント「衣装のボーン合わせ」が追加され、衣装ボーンの Transform が変更される。
7. **元に戻す** を押すと、衣装ボーンを適用前の値に復元し、コンポーネントを削除。適用・元に戻すは、どちらも衣装ごとに 1 回の Ctrl+Z で取り消し可。

コンポーネントの Inspector:

- **ウィンドウを開く**: この衣装とアバターを設定してウィンドウを開く。
- **再適用**: アバターのボーン変更のうち、未反映の分を適用。
- **元に戻す**: ウィンドウの「元に戻す」と同じ。
- **自動追従**（既定オン）: アバターのボーン変更時、編集中に衣装へ再適用。
- **基準アバター**（任意）: 改変前のアバター。未指定時は元 FBX のボーン値を基準値として使用。配布元のプレハブが FBX からボーンの値を変えている場合や、アバターが FBX とのつながりを失っている（Unpack 済み・改変した FBX に差し替え済み）場合に指定。ボーンはアバターのルートからのパスで照合し、該当ボーンが無いと警告「基準アバターに該当ボーンなし」とボーンごとの代わりの取得元を表示。
- 「未反映の変更」「適用済みの変更」の表と、「アバターの変更済みボーン」の一覧。「－」は衣装に該当ボーンなし（そのボーンの変更は追従対象外）。

スクリプトから合わせるときは `OutfitBoneSync.Editor.OutfitBoneSyncMenu.Fit(衣装のルートの GameObject)` を使えます（すぐに適用します）。

アップロード時と Play Mode では、NDMF があれば Modular Avatar の結合より前にもう一度合わせてから、このコンポーネントを消します。

## 仕組み

アバターのボーン a の改変前のワールド行列（Position・Rotation・Scale をまとめた行列）を Rw、今のワールド行列を Cw とすると、体のメッシュは Cw × Rw⁻¹ だけ動いています。衣装の対応するボーン o（合わせる前のワールド行列 Ow）を Cw × Rw⁻¹ × Ow に置きます。衣装のボーンがアバターと同じ値なら、アバターのボーンの値をそのまま写したのと同じになり、衣装のボーンが少し違う場合もその違いを保ちます。

- ボーンの対応付けは Modular Avatar の Merge Armature と同じ（Prefix・Suffix を外した名前で、親から順にたどる）。Merge Armature が無い衣装は、アバターの Hips と同じ名前のボーンからたどります。
- 改変前の値（基準値）は、ボーンごとに、指定した「基準アバター」の同じパスのボーン → プレハブの元の FBX → 体のメッシュの FBX → Animator の Avatar の skeleton、の順で探します（Animator の Avatar の skeleton は指の Rotation が FBX と違うことがあるので最後）。
- 合わせる前の衣装のボーンの値はコンポーネントに控えるので、何度合わせても改変が二重にかかりません。すでに手で改変後の値に合わせてあったボーンは、改変前の値を元として控えます。

## Modular Avatar のロックとの関係

Merge Armature の「位置を元アバターに合わせてリセット」は、アバターのボーンの値をそのまま写します。このツールは改変した分だけを動かすので、衣装独自のボーンのずらしを残せます。

Merge Armature のロック（BaseToMerge）は、ロックを始めた時点の衣装とアバターのずれを保ったまま追従します。そのため、改変済みのアバターにあとから衣装を置くと、ずれたまま固定されます。このツールで合わせると、ロックはその合わせた状態を新しい基準として追従します。

## 注意

- 「自動追従」がオンのとき、手で変えた衣装ボーンの値は、アバターのボーン変更時に上書きされます。衣装ボーンを手で調整するときは「自動追従」をオフにしてください。
- 衣装に無いボーンの改変（例: 衣装に胸のボーンが無いのに胸のボーンを拡大）には追従しません。
- アバターのルートの Scale は、衣装がアバターの子なので、そのまま衣装にもかかります（このツールでは扱いません）。

## 必要なもの

- Unity 2022.3、VRChat SDK（Avatars）
- 任意: NDMF（アップロード時にもう一度合わせる）、Modular Avatar（Merge Armature の対応付けを使う）

## 動作確認した環境

- Unity 2022.3.22f1、VRChat SDK 3.10.6、Modular Avatar 1.18.7、NDMF 1.15.0（2026-11-24）
- しなののボーンを改変したアバターに、しなの用の衣装を着せて確認しました（編集中の見た目と、アップロードと同じ NDMF の処理のあと）。
